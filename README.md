# 🌄 Everscape

**Everscape** is a 3D mountain world built with Babylon.js and TypeScript — optimized for low-end PCs and laptops.

### 🌅 Features (Phase 1)
- Real-time day/night cycle based on system time  
- Mountain terrain with height maps  
- Dynamic lighting and skybox  
- FPS optimization for low-end hardware  
- Modular file architecture for scalability

### 🛠️ Tech Stack
- TypeScript
- Babylon.js
- Vite
- Node.js (for future backend)
- Ubuntu WSL environment

### 🚀 Getting Started
```bash
npm install
npm run dev
```
